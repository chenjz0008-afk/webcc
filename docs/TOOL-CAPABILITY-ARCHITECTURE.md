# 工具能力实现架构

日期：2026-10-07。目标是补齐可执行的工具流程，并逐项减少与 Claude Messages API 的差异。当前只使用网页账号。

## 模块边界

| 模块 | 职责 | 现有代码 |
| --- | --- | --- |
| API 与账号调度 | 认证、权限、并发、超时、取消、选号和错误归属 | manager.py、api_keys.py |
| 客户端工具协议 | 工具声明、历史 ID、参数校验、选择约束和结果回传 | web_tools/ |
| 文档输入 | PDF/文本转换；二进制附件独立传递，历史保留附件对应标记 | web_documents.py、web_tools/media.py |
| 平台文件 | 上传、引用、下载、到期、配额和调用密钥隔离 | web_files.py |
| 网页上游 | 推理、网页搜索、网页读取和网页云端代码执行 | 原版 ClewdR 账号容器 |
| 有状态执行（待实现） | 绑定调用者、账号、上游会话、运行状态及文件资源；取消和恢复 | 独立小模块，禁止散落在路由代码中 |
| 外部执行提供方（待实现） | 远程 MCP；必要时接入独立沙箱或搜索服务 | 采用服务的官方 SDK，按需新增 |

保持单个主应用和 SQLite，不为当前规模引入消息队列、微服务或第二个数据库。主应用不运行模型生成的 shell。原版 ClewdR 作为可升级依赖，固定已验证镜像；更新先在隔离容器回归，再发布。

## 已核实的网页内置能力

| 能力 | 证据 | 不能据此推定的能力 |
| --- | --- | --- |
| web_search | 公网实际工具调用、成功结果、最终来源回答 | 官方搜索声明、域名过滤、次数限制、原生引用和暂停恢复 |
| web_fetch | 公网实际读取 Python 官方页面并回答 | 官方抓取结果协议及所有访问策略 |
| bash_tool | 公网真实 Python 计算，退出码 0，正确结果 | 官方 container ID、跨请求状态、程序化客户端工具桥接 |
| present_files | 公网返回生成 CSV 的 local_resource | 调用者已经下载文件、已获得可复用 Files ID |
| 图片/PDF 阅读 | 普通 Messages 的合成文件读取通过 | 所有格式、所有尺寸或所有工具组合均已通过 |

这些能力优先复用，不因需要标准 API 形状而立即购买另一套搜索或沙箱服务。平台 Files 和 prompt-v1 客户端工具由主项目提供，不属于网页内置能力。

## 实现顺序和验收

1. 附件与客户端工具混用（候选 6 次真实请求及生产完整往返已通过）：同一请求真实读取 PDF/图片后提议工具，客户端执行并回传，模型确认实际保存值；验证工具结果中的附件及跨密钥拒绝。
2. 云端文件下载：先证明能取得正确的账号、组织和会话绑定，并在上游会话和文件仍有效时取得字节。仅凭路径或文件名不能定位文件，禁止从其他账号按同名文件搜索。
3. 有状态沙箱：调用密钥隔离的稳定运行 ID、明确状态转换、过期清理、失败和取消；有副作用后不能盲目换账号重放。
4. 搜索与代码执行标准协议：声明参数、实际执行和结果块同时具备；原生引用位置及 pause_turn 单独验收。
5. MCP 与工具发现：复用官方 MCP SDK；限制允许连接的端点，认证按调用者隔离；发现后才能调用。
6. 程序化工具调用与 Skills：基于已验证的沙箱状态、文件和工具桥接实现，不以接收字段代替实际执行。

每项记录四种状态：未实现、候选实测通过、生产部署、生产实测通过。通过的步骤从执行待办移除，完整官方能力的剩余验收继续保留。

## 网页下载的关键约束

公开开源项目记录了按组织和会话访问的 wiggle/list-files 与 wiggle/download-file。它使用网页认证，下载参数是云端路径。该记录提供调查方向，仍须在本项目固定上游上实测。

固定版本源码中 preserve_chats=false 设置 is_temporary=true；已检查的 chat.rs 没有主动 DELETE，会话和文件的确切失效时机仍待实测。下载实现必须先取得正确绑定并核实会话生命周期。不能在未验证绑定和清理时全局改为长期保留聊天；需要先在隔离候选确定可行方案。若现有 ClewdR 接口没有提供必要会话标识，需要独立网页执行桥接层，或评估独立沙箱提供方，不能声称文件下载已完成。

## 兼容边界

网页生成加本地 JSON Schema 校验不等于官方严格约束采样。网页 thinking 不证明官方签名可回传。缓存统计、官方签名和无法获得的上游权限不伪造。尚未真实提供的接口返回明确错误。
