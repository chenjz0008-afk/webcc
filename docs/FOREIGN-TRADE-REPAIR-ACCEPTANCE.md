## 历史失败记录

首轮 61/96、第二轮 81/96；第三轮 23/24、第四轮 22/23 为发现具体错误后停止时的已完成样本，不能当作完整矩阵。未完成和被中止的会话不计成功。

已定位并修复：空 text 和工具元数据封装、流式过早发布、标准说明块混入工具列表、纠正提示未提供具体 Schema 路径、CSV 类型与缺 pandas、来源代理解析与抓取正文上限。工具参数仍按声明校验，已发出的调用后遇到错误不重放。

后续组件门槛曾因 CSV 触发未知网页工具失败，未启动岗位矩阵；拆开程序生成与 E2B 执行后，CSV 三次独立复验通过。另一次矩阵完成 8 个岗位、7 个通过，广告字段名带前导空格，旧反馈未完整指出未知字段；停止后临时密钥、占用和活动任务均为零。补齐完整参数路径及多条校验错误后，该岗位三次独立复验通过。所有原失败保留，不将中止的矩阵视为完整验收。

报价样本的原检查器将数量 2,500 误匹配为内部亏损数值 500。独立复核实际保存文档：对客内容仅包含 USD2.50 买家报价、USD3.00 反报价及数量，没有供应商成本、亏损和毛利。原始 false 结果保留，另记纠正，不覆盖历史。

后续矩阵停止时完成 72 项，63 项通过：两次广告任务计算后脱离 JSON 工具协议，未保存及回读；另七项被上游拒绝，单独核查状态。清理后临时密钥、占用及活动任务均为零。修复将协议指令与任务数据分开，尚待独立与并发复验。一次最终成功的社媒任务仍记录为体验异常：首稿有无依据的产品或交付表述，回读后自行纠正，完整任务 61.645 秒，发生两次写入与回读。

## 测试范围

真实模型调用在服务器隔离 PostgreSQL/Redis 环境执行，使用已挂载账号；候选与线上共享生产租约上限，合计全局 4、单账号 1。客户端工具操作独立合成 Markdown 资料，没有发送邮件、发布社媒、采购或支付。

每个岗位核对实际保存、保存后回读、计算结果、产品事实及受众。新增检查非目标文档逐字不变及无额外写入。速度记录首事件、首有效内容、首可读文本、完整请求和完整多步任务；失败请求纳入统计。

这是 WorkBuddy 类工作流的 SDK 模拟，不是实际 WorkBuddy 界面或 Word 渲染验收。没有官方 API Key 对照组，不能给出相对官方速度比例。当前真实返回型号与请求型号可能不同；保留实际值，不声称精确模型选择。

Python 继续用于编排；先前候选负载低，没有证明语言是响应速度瓶颈。ClewdR 源码、配置、镜像与账号状态不在本次修复范围。
