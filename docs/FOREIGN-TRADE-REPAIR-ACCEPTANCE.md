## 测试范围

真实模型调用在服务器隔离 PostgreSQL/Redis 环境执行，使用已挂载账号；候选与线上共享生产租约上限，合计全局 4、单账号 1。客户端工具操作独立合成 Markdown 资料，没有发送邮件、发布社媒、采购或支付。

每个岗位核对实际保存、保存后回读、计算结果、产品事实及受众。新增检查非目标文档逐字不变及无额外写入。速度记录首事件、首有效内容、首可读文本、完整请求和完整多步任务；失败请求纳入统计。

这是 WorkBuddy 类工作流的 SDK 模拟，不是实际 WorkBuddy 界面或 Word 渲染验收。没有官方 API Key 对照组，不能给出相对官方速度比例。当前真实返回型号与请求型号可能不同；保留实际值，不声称精确模型选择。
