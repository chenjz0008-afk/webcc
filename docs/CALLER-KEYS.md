# 调用密钥与请求追踪

版本：2026-10-07，开发分支候选。合并与发布前，生产接口保持现有版本。

## 调用密钥

管理台左侧「调用密钥」用于创建、查看和撤销密钥。创建时填写名称、允许使用的账号、功能权限、每分钟请求数和可选到期时间。生成的完整密钥只显示一次，可一键复制；关闭后无法再次读取。

| 配置 | 含义 |
| --- | --- |
| 账号范围 | 必须选择至少一个账号；选号及失败切换都在此范围内进行 |
| 消息调用 | 允许现有 Chat Completions、Messages 与 Code 消息路由；不增加上游资格 |
| 模型列表 | 允许读取现有模型列表；该列表不是账号模型资格证明 |
| 实验工具 | 除消息权限外，还允许请求 `X-WebCC-Tools: prompt-v1`；仍需服务器开启实验开关 |
| RPM | 每个密钥在连续 60 秒窗口中的请求上限，1—1000；不替代全局并发和队列限制 |
| 到期时间 | 管理台按浏览器当地时间输入，后端保存 Unix 秒；留空表示无指定到期时间 |

新密钥支持 `Authorization: Bearer <key>` 与 `x-api-key: <key>`。管理员密码不能用于消息调用，新调用密钥不能访问管理接口。原 `CLEWDR_PASSWORD` 保持兼容，并拥有整个账号池权限。

后端只保存随机密钥的 SHA-256 摘要，管理接口列表不返回摘要或完整密钥。密钥不会作为上游凭据转发。账号的 sessionKey、代理认证和上游密码继续由原账号管理机制处理。

## 生命周期与限流

撤销和到期后返回 401；权限不足返回 403；超过 RPM 返回 429，并附带 `Retry-After` 秒数。通过鉴权的请求计入速率，包括随后发现参数错误的请求。失败切换计作同一次网关请求。

撤销会阻止新请求及尚未获得资源的排队请求；已经开始调用上游的请求可以完成。速率窗口保存在进程内，重启后重新计数；密钥、到期和撤销状态持久保存。当前最多保存 128 个密钥记录，包括已撤销记录，不提供金额预算、计费、团队 RBAC 或 Files 命名空间。

## 管理接口

以下接口使用管理员 Bearer 凭据：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/admin/api-keys` | 获取脱敏列表 |
| POST | `/admin/api-keys` | 创建密钥，成功返回 201，完整 `key` 仅本次返回 |
| POST | `/admin/api-keys/{id}/revoke` | 撤销密钥；成功返回 `{ "ok": true }` |

创建请求示例，账号 ID 从 `/admin/accounts` 获取：

```json
{"name":"document-app","accounts":["账号ID"],"scopes":["messages","models"],"rpm":30,"expires_at":null}
```

## Claude 错误与请求 ID

Messages、Models 及预留 Files/Skills 路由的错误使用 `type: error`、`error.type`、`error.message`、`request_id`。预留路径仍返回不支持错误，不代表已经实现 Files 或 Skills。

每次请求由网关生成请求 ID，同时返回 `Request-Id` 和原有 `X-Request-Id`。客户端自行传入的 ID 不替代网关 ID；不向调用者公开账号上游的请求 ID。OpenAI 路由保留原错误正文结构。

本候选覆盖参数、鉴权、权限、资源、体积、限流、内部故障与超时等状态映射。独立密钥 RPM 有 `Retry-After`；所有上游限流恢复头、反向代理生成的错误和真实流内故障仍列入后续验收。

设计依据：[Claude 错误协议](https://platform.claude.com/docs/en/api/errors)、[LiteLLM 虚拟密钥](https://docs.litellm.ai/docs/proxy/virtual_keys)。WebCC 沿用现有管理和调度层，不修改 ClewdR，也没有增加第二套数据库或网关。
