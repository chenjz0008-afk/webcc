# 实验网关与官方 SDK 验收

日期：2026-10-06。分支：feat/web-tool-history。状态：候选实现通过本轮验收，尚未部署生产。

## 实现

主网关增加默认关闭的 MANAGER_WEB_TOOLS_ENABLED 开关。请求还必须携带 X-WebCC-Tools: prompt-v1、指定 webcc-prompt-v1 模型别名，并调用 /v1/messages。普通调用继续使用现有转发；缺少请求头的实验模型别名明确拒绝。

工具适配移入独立 web_tools 包，实验程序复用它。包负责校验历史、Schema、选择规则和容量，构建网页提示并验证完整结果。网关只返回客户端操作提议，业务工具由客户端执行。官方 ClewdR 镜像和源码没有修改。

SSE 先缓冲上游结果，校验后输出 message_start、工具或文本内容块、参数增量、结束原因及 message_stop。等待期间发送 ping；失败发送 error。它不是原生实时生成，不提供 thinking 签名或官方 strict。使用独立模型别名，避免把未验证的实际模型身份写成官方型号。

真实模型请求共 18 次；另外 3 次非法 ID 请求在网关内拒绝。每个文档流程通过 SDK 发出双读取，反序回传结果，收到模拟版本冲突后重新读取、修改 B 并读回。A 保持数量 7，B 从 19 改为 10，货币 EUR 保持，每次流程只有一次成功修改。误导文档样例没有导致修改 A。详情见 [脱敏记录](web-tool-gateway-2026-10-06.json)。

SDK 使用显式临时 key、Base URL 和官方 DefaultHttpxClient(trust_env=False)，SDK 自动重试关闭。候选网关调用临时官方容器，容器仅允许对应账号代理出口。本机 Claude Code、登录态和本机模型出口未用于测试。当前 SDK v1 使用 httpx2，测试程序已按官方接口处理。

HTTP 500 切换、三次失败隔离阈值、坏格式不隔离、排队取消和生成中断开等使用可控上游模拟，未故意破坏生产账号或代理。不将这些模拟故障称为真实上游故障验收。取消验证了本地连接与槽位释放，不保证网页上游停止生成或返还额度。

## 请求隐私核查

只读核查生产实际代码：网关连接账号容器的 loopback 端口，仅转发明确允许的协议请求头，不转发客户端 User-Agent、X-Forwarded-For、X-Real-IP、Forwarded 或主机名请求头。11 个运行账号均配置代理。实验接口同样采用请求头白名单，新增模拟身份回归测试覆盖普通与实验路径。

本轮真实 SDK 请求在服务器执行，未使用本机 Claude Code 或本机文件；临时测试容器通过出口防火墙限制为账号代理。该测试不等于已对生产容器完成断代理和抓包验收，也不能保证客户端主动写入 messages、system、tools、tool_result 或普通接口请求体的本机信息被清除。SSH 来源 IP 对服务器可见，与 Claude 模型出口不同。

## 边界与后续

模型别名代表网页提示策略，不能证明实际模型型号。usage 保留上游报告，包含包装提示和原始 JSON 输出，不是变换后消息的精确计数。格式校验不能保证模型总能遵守，也不能代替客户端对修改的权限、版本与幂等检查。

实际 WordBuddy、TypeScript SDK、生产 HTTPS、真实文件格式保持、复杂注入和更广的上下文尚未验收。E01 继续保留这些门槛，原生 C05—C11 等任务不删除。生产对外 API 文档没有新增未发布的能力。

候选使用方式见 [实验接口说明](EXPERIMENTAL-TOOLS-API.md)。发布前需审查和合并，按开发说明备份、候选验证后再启用；不应直接覆盖生产私有配置或账号数据。
